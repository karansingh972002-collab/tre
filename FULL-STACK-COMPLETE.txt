┌──────────────────────────────────────────────────────────────┐
│            🔄 DATA FLOW - COMPLETE CYCLE                     │
└──────────────────────────────────────────────────────────────┘

User Action → Frontend Form → API Request → Backend Validation
     ↓                                              ↓
Database Update ← Backend Response ← Auth Check ← Token Verify
     ↓
Update UI ← Notification ← Success Response

Example: User Recharges ₹1000
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. User fills recharge form (Frontend)
2. Clicks "Recharge Now" button
3. Frontend sends POST /api/wallet/recharge
4. Backend verifies JWT token
5. Backend validates amount ≥ ₹100
6. Backend fetches wallet from database
7. Backend creates transaction record
8. Backend updates wallet.availableBalance (+₹1000)
9. Backend creates notification
10. Backend returns success + new balance
11. Frontend shows success toast
12. Frontend auto-refreshes
13. User sees updated balance immediately
