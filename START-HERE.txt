================================================================================
                         ALPHAMINE WEBSITE - START HERE
================================================================================

The functional website is now the production server in this folder.

It includes:
- Home page
- Register and login
- VIP and SVIP plan listing
- Wallet recharge with generated UTR
- Plan purchase from wallet balance
- Withdraw requests
- Referral code and referral link
- Support form
- Payment complaint form
- Admin panel for plans, QR/payment details, transactions, complaints, and users

================================================================================
                             RUN THE WEBSITE
================================================================================

From this folder, run:

  npm run dev

Then open:

  http://localhost:8080

Admin page:

  http://localhost:8080/#admin

Default admin password:

  admin123

To use a different port:

  PORT=8090 npm run dev

================================================================================
                                DATA STORAGE
================================================================================

The website saves live data here:

  data/production-db.json

You do not need Prisma, Supabase, PostgreSQL, or environment setup for the local
functional version.

================================================================================
                              QUICK TEST FLOW
================================================================================

1. Open http://localhost:8080
2. Register a new account
3. Recharge wallet
4. Buy a VIP or SVIP plan
5. Open dashboard to see wallet, income, and transactions
6. Open Admin with password admin123 to manage plans and payment settings
