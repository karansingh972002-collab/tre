3. Create new project (wait 2 min)
4. Get connection string from Project Settings → Database
5. Put in .env.local file
6. Run these commands:

   npx prisma generate
   npx prisma db push
   npm run db:seed
   npm run dev

7. Open http://localhost:3000

Replace with YOUR Supabase connection string.
