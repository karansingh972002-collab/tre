═══════════════════════════════════════════════════════════════
               📊 DATA FLOW EXAMPLE
═══════════════════════════════════════════════════════════════

User Recharge Flow:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. User enters amount (₹1000)
2. Selects payment method (UPI/Card)
3. Frontend sends to: POST /api/wallet/recharge
4. Backend verifies user token
5. Backend fetches wallet from database
6. Backend creates transaction record
7. Backend updates wallet balance (+₹1000)
8. Backend creates notification
9. Backend returns success + new balance
10. Frontend shows success toast
11. Frontend refreshes page
12. User sees updated balance

User Withdrawal Flow:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. User enters amount (₹500)
2. Enters bank details (Account + IFSC)
3. Frontend sends to: POST /api/wallet/withdraw
4. Backend verifies sufficient balance
5. Backend creates withdrawal request (PENDING)
6. Backend moves money to locked balance
7. Backend creates transaction record
8. Backend creates notification
9. Backend returns success
10. Frontend shows success toast
11. Frontend refreshes history
12. Admin approves from admin panel
13. Status changes to APPROVED → COMPLETED

Support Ticket Flow:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. User fills subject & message
2. Frontend sends to: POST /api/support/tickets
3. Backend creates ticket (status: OPEN)
4. Backend creates notification
5. Backend returns ticket ID
6. Frontend shows success toast
7. Frontend refreshes ticket list
8. User sees ticket in "Recent Tickets"
9. Support team responds via admin panel
10. User gets notification of response
